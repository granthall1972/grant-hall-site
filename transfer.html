Transfer

Direct browser-to-browser file transfer. No upload — the file goes straight between the two of you. Trade the codes as text or by QR.

1. Choose a file
2. Send this code to the other person
3. Paste their reply code (or scan it), then connect
1. Paste the code you were given (or scan it)
2. Send this reply code back to the sender
