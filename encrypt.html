Encrypt

Password-encrypt a file with AES-256-GCM. Everything runs in your browser — the file never leaves the page.

File
Password
Confirm password

AES-256-GCM, key from PBKDF2-SHA-256 (600,000 iterations), random salt and IV per file. A forgotten password cannot be recovered. Large files are held in memory and may fail on low-RAM devices.
