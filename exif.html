EXIF

Read, edit, or strip the metadata in a JPEG. Runs in the browser.

JPEG file
Edit fields (blank removes the tag)
Description
Artist
Copyright
Software
Camera make
Camera model
Lens
Date taken (YYYY:MM:DD HH:MM:SS)
Orientation
GPS latitude (decimal)
GPS longitude (decimal)
All metadata

The file never leaves your browser. EXIF read/edit/strip here is JPEG only; it uses the piexifjs library, vendored on this site. "Stripped" removes the whole EXIF block. Editing rewrites it, keeping any tags you don't touch.
